## Publicar con GitHub Pages

1. Crea un repositorio **público** en GitHub, por ejemplo `redes-4eso`.
2. Pulsa **Add file → Upload files**, arrastra **todo el contenido de esta carpeta** (incluida la carpeta `img`) y pulsa **Commit changes**.
3. Ve a **Settings → Pages**. En *Source* elige **Deploy from a branch**, rama **main**, carpeta **/ (root)**, y pulsa **Save**.
4. En uno o dos minutos la web estará en `https://TU_USUARIO.github.io/redes-4eso/`.

Para cambiar algo más adelante, vuelve a subir el archivo con el mismo nombre: se sustituye.
